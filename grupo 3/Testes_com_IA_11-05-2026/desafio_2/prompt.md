# Prompt de Resposta - Análise de Testes de Cálculo de desconto

## Prompt do Usuário

Tenha em vista que:

**Regras de negócio:**
 - Valor da compra menor que 0 = ValueError
 - Cliente VIP = 15% de desconto
 - Compra maior ou igual a R$ 300 = 10% de desconto
 - Demais casos = Sem desconto
 - Cliente VIP com compra ≥ R$ 300 = Aplica desconto VIP de 15%

**Responda:**
 - Quais regras definem os descontos aplicados?
 - Existe prioridade entre as regras?
 - Quais cenários devem ser validados pelos testes?
